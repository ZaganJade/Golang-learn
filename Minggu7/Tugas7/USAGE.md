Berkas ini saya buat untuk mencantumkan dengan jelas bagian mana pada tugas
ini yang dibantu AI, supaya laporannya tetap jujur.

## Bagian yang dibantu AI (EyAy Agentic)

- **Dokumentasi API pada `README.md`.** Saya minta bantuan EyAy untuk
  menyusun ulang dokumentasi ini setelah struktur proyek berubah, meliputi
  struktur folder, pemetaan ke empat layer Clean Architecture, tabel
  variabel environment, dan tabel kontrak API.
